ONLYUSLABS — COMPLETE PUBLIC-PAGE DARK MODE FIX
================================================

This package fixes incomplete dark-mode styling across the public website.

What was addressed:
- Homepage and shared navigation.
- About page and values sections.
- Solutions landing and individual solution pages.
- Digital marketing page.
- Industries landing and individual industry pages.
- Healthcare page and healthcare solution sections.
- Portfolio listing and individual case studies.
- Project cards, project details, workflow panels and technology chips.
- Testimonials and empty states.
- Contact form, budget controls, consent text and success/error states.
- Privacy and Terms pages.
- Insights page.
- 404 page.
- Footer and intentionally dark sections.

The existing saved theme preference is preserved:
- Light/dark selection continues to use the existing localStorage key.
- System preference is respected when no visitor choice is saved.
- Theme toggle remains available on every public page using site.css.
- Dark-mode form controls and selection colours are corrected.

Scope:
- Public website pages are fixed.
- The separate administrator dashboard and admin login use their own stylesheets
  and remain on their existing light administration theme.

No Supabase migration, DNS change or WhatsApp configuration change is required.

Deployment:
1. Extract the ZIP.
2. Upload the extracted folder to the existing Netlify site.
3. If the browser still shows old styles, perform a hard refresh or clear the
   site's cached assets.
